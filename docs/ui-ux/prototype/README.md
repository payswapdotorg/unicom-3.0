# Standalone UI prototype

Open [UNiCOM-Interactive-UI-Prototype.html](UNiCOM-Interactive-UI-Prototype.html) directly in a modern browser. It is a dependency-free design reference for the workspace shell, New Task, Buying, Opportunities, My Store, settings, and docked Browser/Terminal affordances.

The file uses local demo data only. It does not connect to providers or network nodes and cannot publish listings, send enquiries, reserve inventory, place orders, transfer assets or run terminal commands. The complete implementation requirements are in the parent design contract and acceptance matrix.

This is a UI reference, not an implementation of production UNiCOM services.
