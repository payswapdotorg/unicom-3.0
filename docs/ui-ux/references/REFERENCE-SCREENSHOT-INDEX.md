## UNiCOM-specific design target

The approved interactive My Store experience is in [the prototype](../prototype/UNiCOM-Interactive-UI-Prototype.html). It replaces the user-facing Device destination with a storefront owned by the user's UNiCOM identity and supports sale, rent, permanent swap, temporary swap/loan, free/giveaway and wanted listings. Temporary swap/loan requires a return-by date/time.

## Asset fidelity note

The committed contact sheet is a low-weight visual index; it is not a substitute for the original-resolution images. The original six screenshot files remain in the operator-supplied `unicom.zip` attachment and are not individually mirrored in this repository snapshot. The design contract and acceptance matrix transcribe the rules required for implementation. Do not claim the original raster files are individually present in this repository.
